# Slim-DETR: Real-Time Tiny Object Detection with Efficient Interaction and Gaussian Query

**论文**: [ECCV 2026 virtual](https://eccv.ecva.net/virtual/2026/poster/4625)  
**任务**: 实时微小目标检测 / 高分辨率场景

## 一句话总结

Slim-DETR 面向无人机与遥感中的微小目标检测，用高效跨尺度交互降低高分辨率计算开销，并用高斯查询显式建模小目标的空间不确定性，在保持实时推理的同时提升 AP_small。

## 研究背景与问题

微小目标检测在无人机巡检、遥感解译等场景中至关重要，但存在两个矛盾：一是小目标像素占比极低，需要保留高分辨率特征；二是 DETR 类模型的全局交互在高分辨率输入下计算量爆炸。已有方法要么牺牲分辨率导致小目标漏检，要么依赖重型注意力导致无法实时。

## 方法总览

论文从查询设计和跨尺度交互两个角度做减法：

1. **高效交互（Efficient Interaction）**：限制跨层注意力的作用范围，让查询只与信息相关的特征位置交互，避免全图全局注意力。
2. **高斯查询（Gaussian Query）**：把小目标位置建模为高斯分布先验，查询在分布附近聚合证据，缓解小目标定位抖动与漏检。

```mermaid
flowchart LR
    X[高分辨率输入] --> E[骨干特征]
    E --> I[高效跨尺度交互]
    I --> Q[高斯查询建模]
    Q --> D[轻量解码器]
    D --> Y[实时检测结果]
```

## 方法详解

- 高斯查询将空间先验显式注入查询初始化与更新过程，使小目标对应的查询在解码过程中更稳定，减少查询漂移。
- 高效交互通过稀疏化或局部化跨层注意力，将计算集中在可能存在小目标的区域，控制高分辨率下的访存与延迟。
- 整体设计目标是把 DETR 的端到端优势带入微小目标场景，同时满足无人机与遥感平台的实时约束。

## 实验与证据

- 在无人机/遥感微小目标基准上与实时检测器比较，报告 AP、AP_small 与端到端延迟。
- 论文强调实时性，因此延迟与精度需同时报告；虚拟站点信息有限，具体数字以正式论文为准。
- 与 SAHI 类切片推理路线相比，该方法是模型内改进，不需要推理时的滑窗开销。

## 对 YOLO-Agent 的启发

- 当 AP_small 是主要瓶颈且当前模型是 DETR 系时，可把"高斯查询 + 高效交互"作为一组候选组件。
- 先用小规模高分辨率数据做短训练筛选，再决定是否迁移到主训练配置。
- 评估必须包含目标设备的实际延迟，而不是只看 FLOPs；高分辨率输入下的访存往往是瓶颈。
- 与切片推理（SAHI）方案做同预算对照，选择"模型内改进"或"推理外切片"中性价比更高的一条。

## 优点

- 同时抓住小目标建模和实时性两个工程痛点，问题定义清晰。
- 查询建模改动属于 DETR 内部结构，便于与现有 DETR 系训练管线组合。
